# Sheriff Department Panel — Majestic RP

Полноценная веб-панель управления Sheriff Department: сотрудники, отчёты, статистика,
настоящие Google Forms и Google Docs, передача заявок и отчётов в Discord, журнал действий
и резервное копирование.

**Ключевой принцип:** заявки рассматриваются **только в Discord**. Сайт отвечает за приём
ответов, техучёт доставки и статистику — он не дублирует модерацию и не создаёт систему
повышений сотрудников.

## Возможности

- **Авторизация по общему паролю** с ролями: Лидер / Заместитель (настраиваемые права) /
  Куратор / Сотрудник (видит только свои отчёты). Все проверки прав — на сервере.
- **Dashboard**: карточки статистики, графики заявок/отчётов по дням, топ активных
  сотрудников, сравнение периодов (день/неделя/месяц/произвольный), последние события,
  состояние интеграций, быстрые действия.
- **Сотрудники**: добавление/редактирование/удаление, поиск по никнейму и Static/ID,
  фильтр по званию, карточка сотрудника с историей отчётов и отметкой «Отчёт отсутствует».
- **Google Forms**: конструктор на 5 шаблонах (вступление, отчёт, отпуск/неактив,
  переаттестация, пустая), создание **настоящей** формы в вашем Google-аккаунте через
  Forms API, ссылки для публикации, техистория доставки ответов.
- **Приём ответов**: Google Apps Script → защищённый endpoint → PostgreSQL → Discord
  (идемпотентно по ID события; повторная доставка не создаёт дубликатов).
- **Discord**: 4 вебхука по назначениям (заявки/отчёты/тех/статистика), включение,
  реальная проверка, тест-сообщения, статус последней доставки, очередь с повторами,
  ручная повторная отправка.
- **Отчёты**: история с фильтрами (никнейм, тип, период, статус доставки), подробности,
  статистика сотрудников (день/неделя/месяц/период), список «без отчётов».
- **Документы**: приказы и отчёты о работе — настоящие Google Docs с предпросмотром;
  отчёт автоматически наполняется статистикой за период.
- **Журнал действий**, **уведомления на сайте**, **экспорт CSV (UTF-8 BOM) / Excel**,
  **диагностика сервисов**, **ежедневное резервное копирование** в Discord/Google Drive.

## Стек

| Слой | Технологии |
|------|------------|
| Frontend | React 18, TypeScript, Vite, React Router, Recharts, современный CSS (тёмная тема Sheriff) |
| Backend | Node.js 20+, Express 4, TypeScript, REST API, Zod-валидация |
| База | PostgreSQL, Prisma ORM, SQL-миграции (применяются автоматически при старте) |
| Интеграции | Google Forms/Docs/Drive API (OAuth), Google Apps Script, Discord Webhooks |
| Развёртывание | GitHub → Railway (Nixpacks), healthcheck `/api/health` |

## Быстрый старт локально

```bash
npm install
cp .env.example .env            # заполните DATABASE_URL, SESSION_SECRET, SETUP_SECRET
npm run db:generate             # генерация Prisma Client
npx prisma migrate deploy       # применение миграций
npm run build                   # сборка клиента и сервера
npm start                       # запуск на http://localhost:3000
```

При первом открытии страница предложит **задать общий пароль** (потребует `SETUP_SECRET`,
если он указан в `.env`).

Для разработки с hot-reload: `npm run dev` (сервер :3001, Vite :5173 с прокси `/api`).

Полный список с пояснениями — в [.env.example](.env.example). Обязательный минимум:

## Безопасность

- Пароль только в виде bcrypt-хеша (env `ADMIN_PASSWORD_HASH` или одноразовая настройка).
- Сессии — подписанные HMAC-SHA256 токены в httpOnly + SameSite=Lax (+Secure в production) cookie.
- CSRF-защита изменяющих запросов (заголовок + проверка Origin), rate-limit входа
  с блокировкой после 5 неудач, мягкий лимит на весь API.
- Секреты (вебхуки, Google-токены) шифруются AES-256-GCM и наружу отдаются только маской.
- Пароли и секреты не логируются; ошибки наружу — без стектрейсов.

## Тесты

`npm test` — покрытие ключевых сценариев: подпись/проверка токенов, шифрование секретов,
нормализация никнеймов, идемпотентность приёма, backoff очереди, сборка Discord-embed,
CSV с BOM, права ролей, шаблоны форм/документов. Сквозной smoke-тест API: `npm run smoke`
(требует запущенный сервер и БД).
