# Sheriff Department Panel — Majestic RP

Полноценная веб-панель управления Sheriff Department: сотрудники, отчёты, статистика,
настоящие Google Forms и Google Docs, передача заявок и отчётов в Discord, журнал действий
и резервное копирование.

**Ключевой принцип:** заявки рассматриваются **только в Discord**. Сайт отвечает за приём
ответов, техучёт доставки и статистику — он не дублирует модерацию и не создаёт систему
повышений сотрудников.

## Возможности

- **Авторизация по паролю** с ролями: Лидер / Заместитель / Куратор / Сотрудник
  (видит только свои отчёты). Первоначальная настройка лидера — через `SETUP_SECRET`
  или `ADMIN_PASSWORD_HASH`. Все проверки прав — на сервере.
- **Дашборд**: карточки статистики, графики ответов/отчётов по дням, состояние доставки,
  последние события.
- **Сотрудники**: добавление/редактирование, поиск по ФИО/ID/Discord, звания и
  подразделения, увольнение/восстановление, карточка с историей отчётов и меткой
  «Отчёт отсутствует», доступ к панели (логин/пароль, сброс пароля).
- **Формы (5 шаблонов)**: вступление, отчёт, отпуск/неактив, переаттестация, пустая.
  Конструктор с вопросами, создание **настоящей Google Формы** через Forms API.
- **Настройки Discord-вебхука для каждой формы**: URL (шифруется AES-256-GCM),
  текст сообщения, упоминание, цвет линии embed, аватарка, имя отправителя,
  заголовок, footer, время. Живой предпросмотр сообщения, кнопка «Проверить вебхук».
- **Приём ответов**: Google Apps Script (триггер onFormSubmit, на основе рабочего
  скрипта) → защищённый endpoint → PostgreSQL → Discord. Идемпотентность по ID ответа
  — повторная отправка не создаёт дублей. Сопоставление сотрудника по игровому ID /
  Discord-тегу / никнейму, метки «Сотрудник не найден», «Форма не найдена».
- **Очередь доставки DeliveryJob**: ретраи с экспоненциальным backoff (до 1 часа,
  5 попыток), без дублей (dedupeKey), ручная переотправка, статусы и ошибки.
- **Отчёты**: из форм-отчётов автоматически, ручные — от руководства; фильтры,
  список сотрудников «без отчётов», экспорт.
- **Документы**: настоящие Google Docs; отчёт о работе автонаполняется реальной
  статистикой за период.
- **Статистика только из реальных данных**: по дням, по формам, по статусам,
  топ активных сотрудников; публикация в Discord; таймзона `APP_TIMEZONE`.
- **Уведомления в панели**, **журнал действий** (аудит без секретов),
  **экспорт CSV UTF-8 BOM** (открывается в Excel), **диагностика интеграций**,
  **ежедневные резервные копии** в Discord/Google Drive.

## Стек

| Слой | Технологии |
|------|------------|
| Frontend | React 18, TypeScript, Vite, React Router, Recharts, тёмная тема Sheriff |
| Backend | Node.js 18+, Express 4, TypeScript, REST API, Zod-валидация |
| База | PostgreSQL, Prisma ORM, SQL-миграции (применяются автоматически при старте) |
| Интеграции | Google Forms/Docs/Drive API (сервисный аккаунт), Google Apps Script, Discord Webhooks |
| Развёртывание | GitHub → Railway (Nixpacks), healthcheck `/api/health` |

## Быстрый старт локально

```bash
npm install
cp .env.example .env            # заполните DATABASE_URL, SESSION_SECRET, SETUP_SECRET
npm run db:generate             # генерация Prisma Client (при необходимости)
npx prisma migrate deploy       # применение миграций (нужен PostgreSQL)
npm run build                   # сборка клиента и сервера
npm start                       # запуск на http://localhost:3000
```

Первое открытие предложит **создать аккаунт лидера** (потребует `SETUP_SECRET`,
если он указан в `.env`).

Для разработки с hot-reload: `npm run dev` (сервер :3001, Vite :5173 с прокси `/api`).

## Переменные окружения

Полный список с пояснениями — в [.env.example](.env.example). Обязательный минимум:
`DATABASE_URL`, `SESSION_SECRET`. Рекомендуются: `ENCRYPTION_KEY`, `SETUP_SECRET`,
`INTEGRATION_SHARED_SECRET`, `APP_TIMEZONE`.

## Безопасность

- Пароли только в виде bcrypt-хэшей; вход ограничен rate-limit'ом (5 неудач за 15 минут).
- Сессии — подписанные HMAC-SHA256 токены в httpOnly + SameSite=Lax (+Secure в production) cookie.
- CSRF-защита изменяющих запросов (заголовок + проверка Origin), мягкий лимит на весь API.
- Секреты (URL вебхуков форм) шифруются AES-256-GCM (`ENCRYPTION_KEY`) и наружу
  отдаются только маской `https://discord.com/api/webhooks/123…/••••••`.
- Endpoint приёма ответов защищён общим секретом `X-Shared-Secret`.
- Пароли и секреты не логируются; аудит-лог маскирует секретные поля; ошибки наружу
  — без стектрейсов. Никаких секретов в коде и репозитории.

## Тесты

`npm test` — 19 unit-тестов: подпись/подделка/просрочка токенов, AES-256-GCM,
сборка Discord-embed (разбивка полей по 1024, цвет/аватар/footer, упоминания),
CSV с BOM и экранированием, нормализация никнеймов, backoff очереди.
Сквозной smoke-тест API: `npm run smoke` (требует запущенный сервер; с БД
проверяет и первичную настройку).
