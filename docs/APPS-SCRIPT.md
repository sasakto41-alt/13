# Google Apps Script — приём ответов форм

Google Forms API не присылает уведомления о новых ответах, поэтому панель использует
тот же механизм, что и ваш рабочий скрипт: триггер **onFormSubmit** в Apps Script.
Отличие: скрипт отправляет ответ не напрямую в Discord, а в панель — Discord-сообщение
формируется по настройкам вебхука конкретной формы (текст, цвет, аватарка).

## Установка (2 минуты на форму)

1. Откройте Google Форму → меню «⋮» (три точки) → **Редактор скриптов**.
2. Удалите содержимое редактора.
3. В панели: **Формы → конструктор формы → кнопка «Apps Script»** — скопируйте
   сгенерированный код. В нём уже подставлены:
   - `PANEL_URL` — адрес вашей панели;
   - `SHARED_SECRET` — общий секрет (переменная `INTEGRATION_SHARED_SECRET`);
   - `FORM_KEY` — ключ этой формы.
4. Вставьте код, сохраните (Ctrl+S).
5. Слева иконка **«Триггеры» (будильник)** → «Добавить триггер»:
   - функция: **onSubmit**;
   - источник события: **Из формы**;
   - тип: **При отправке формы** → Сохранить.

## Как это работает

```
Google Form ──(триггер onSubmit)──> Apps Script ──POST /api/integrations/ingest──> Панель
                                                                                     │
                                              PostgreSQL (идемпотентно по ID ответа) ┤
                                                                                     ▼
                                              Discord-вебхук формы (текст/цвет/аватарка)
```

- Панель сопоставляет ответ с сотрудником по игровому ID → Discord-тегу → никнейму
  (нормализованное сравнение). Если сотрудник не найден — в панели появится метка
  **«Сотрудник не найден»**, а сообщение всё равно уйдёт в Discord.
- Ответы на форму типа «Отчёт» автоматически создают отчёт сотруднику.
- Повторная отправка одного и того же ответа (сбой, ретрай Apps Script) **не создаёт дублей**.

## Проверка

1. Заполните форму тестовыми данными.
2. Панель → «Ответы форм» — ответ появился, статус «Доставлено в Discord».
3. Discord — сообщение с настройками вебхука формы.
4. Если статус «Сотрудник не найден» — проверьте, что игровой ID / Discord-тег /
   ФИО заполнены в карточке сотрудника и совпадают с ответом в форме.

## Частые проблемы

- **Ошибка авторизации при сохранении триггера** — это нормально: Google просит разрешение
  от вашего аккаунта (скрипт шлёт только исходящие запросы). Выберите свой аккаунт →
  Advanced → Go to project (unsafe) → Allow.
- **401 в логах выполнения скрипта** — не совпадает `SHARED_SECRET` или на сервере не задан
  `INTEGRATION_SHARED_SECRET`.
- **Не уходят ответы** — проверьте, что в конструкторе формы включено «Отправлять ответы
  формы в Discord» и задан вебхук (или глобальный `DISCORD_APPLICATIONS_WEBHOOK_URL`).
