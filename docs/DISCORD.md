# Discord — вебхуки и безопасность

## Создание вебхука

1. В Discord: настройки канала (шестерёнка) → **Интеграции** → **Вебхуки** → «Новый вебхук».
2. Задайте имя и канал → **Копировать URL вебхука**. Формат:
   `https://discord.com/api/webhooks/123456.../AbCdEf...`

## Два уровня настройки

### 1) Пер-формный (приоритет) — в конструкторе форм

Для **каждой формы** в панели настраивается собственное сообщение:
- **URL вебхука** — хранится на сервере зашифрованным (AES-256-GCM), в UI видна только маска;
- **текст сообщения** (content) и упоминание `@everyone` / `@here`;
- **цвет линии embed** (палитра + hex);
- **аватарка** (ссылка на изображение) и имя отправителя;
- заголовок embed и текст снизу (footer), время ответа.

Формат сообщения совпадает с обычным Discord-вебхуком: контент над embed, поля
«вопрос → ответ» (длинные ответы автоматически разбиваются на части по 1024 символа).

Кнопка **«Проверить вебхук»** в конструкторе отправляет тестовое сообщение в Discord.

### 2) Глобальные вебхуки — в Railway → Variables

| Переменная | Назначение |
|------------|------------|
| `DISCORD_APPLICATIONS_WEBHOOK_URL` | ответы форм, если у формы не задан свой вебхук |
| `DISCORD_REPORTS_WEBHOOK_URL` | резерв под отчёты |
| `DISCORD_TECH_WEBHOOK_URL` | технические события |
| `DISCORD_STATS_WEBHOOK_URL` | кнопка «Опубликовать статистику» |
| `DISCORD_BACKUP_WEBHOOK_URL` | ежедневные резервные копии (JSON-файл) |

Если ни пер-формный, ни глобальный вебхук не задан — ответ сохраняется в панели,
а доставка помечается как «Не настроено»; настроите вебхук и нажмёте «Переотправить»
в разделе «Ответы форм».

## Надёжность доставки

- Сообщения уходят через **очередь DeliveryJob**: ретраи с экспоненциальной паузой
  (1 → 2 → 4 … минут, максимум 1 час), до 5 попыток.
- Повторная отправка одного и того же ответа **не создаёт дублей** (ключ идемпотентности).
- Неудачные задачи видны в разделе «Очередь доставки»: маскированный URL, ошибка,
  номер попытки, кнопки «Переотправить»/«Отменить».
- При окончательном провале приходит уведомление в панели.

## Безопасность

- URL вебхуков — секреты: в БД шифруются, наружу отдаются только маской
  `https://discord.com/api/webhooks/123…/••••••`.
- Если вебхук случайно «слился» — удалите его в Discord и создайте новый,
  затем замените URL в панели/на сервере.
- У вебхука Discord нет истечения срока — отзывайте неиспользуемые.
