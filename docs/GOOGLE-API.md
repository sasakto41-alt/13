# Google API — настройка сервисного аккаунта

Панель создаёт **настоящие** Google Формы (Forms API) и Google Документы (Docs API)
через сервисный аккаунт. Это требует одноразовой настройки в Google Cloud Console.

## Шаги

1. **Создайте проект**
   - Откройте <https://console.cloud.google.com/>
   - «Select a project» → «New Project» → имя, например `sheriff-panel` → Create.

2. **Включите API** (меню → APIs & Services → Library, для каждого нажмите Enable):
   - **Google Forms API**
   - **Google Docs API**
   - **Google Drive API**
   - (при запросе — включите согласие OAuth, тип Internal/External без областей —
     для сервисного аккаунта это формальность)

3. **Создайте сервисный аккаунт**
   - APIs & Services → Credentials → «Create Credentials» → **Service account**.
   - Имя: `sheriff-panel`. Роли можно не назначать → Done.

4. **Скачайте ключ**
   - Откройте созданный аккаунт → вкладка **Keys** → «Add key» → **Create new key** → **JSON**.
   - Скачается файл с полями `client_email`, `private_key` и др. **Это секрет.**

5. **Передайте ключ панели** — один из способов:
   - Railway → Variables → `GOOGLE_SERVICE_ACCOUNT_JSON` = содержимое JSON-файла одной строкой;
   - или `GOOGLE_SERVICE_ACCOUNT_FILE` = путь к файлу внутри контейнера.

6. **Проверка**
   - Панель → Настройки → Интеграции: Google API должен показать статус **«Настроено»**.

## Что умеет панель с Google

| Действие | Где | API |
|----------|-----|-----|
| Создать Google Форму по вопросам из конструктора | Формы → Конструктор → «Создать в Google» | Forms API |
| Открыть ссылку формы для редактирования/заполнения | карточка формы | — |
| Создать Google Документ (в т.ч. автонаполняемый отчёт о работе) | Документы → «Добавить документ» | Docs API + Drive |
| Ежедневные копии в Google Drive | автоматом, если настроен Google | Drive API |

## Частые проблемы

- **403 PERMISSION_DENIED / `Google API не настроено`** — не включён один из трёх API (Forms/Docs/Drive).
- **invalid_grant** — в JSON-ключе повреждены переносы в `private_key`. Вставляйте JSON целиком одной строкой.
- Формы/документы создаёт сервисный аккаунт — они лежат в его Drive. Панель автоматически открывает
  доступ «всем по ссылке» (чтение). Для просмотра от своего аккаунта откройте ссылку из панели.

## Ответы форм: как попадают в панель

Google Forms API не присылает уведомления о новых ответах напрямую. Ответы собирает
**Google Apps Script** (триггер «при отправке формы»), установленный в каждой форме:
он отправляет их на защищённый endpoint панели. Инструкция: [APPS-SCRIPT.md](APPS-SCRIPT.md).
